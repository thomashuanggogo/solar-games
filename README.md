# ☀️ 太陽能互動實驗室

給高中生的三個太陽能物理互動模擬。單一 HTML、零外部依賴、手機可玩、離線可玩。

## 三關

| 關卡 | 主題 | 玩法 |
|------|------|------|
| [第 1 關](01-photoelectric-effect.html) | 🔬 光電效應實驗室 | 拖波長滑桿，看什麼顏色的光打得出電子；找出極限波長 |
| [第 2 關](02-bandgap-spectrum.html) | 🌈 能隙與太陽光譜 | 拖能隙滑桿，看太陽光被切成三段；找出效率最高的能隙 |
| [第 3 關](03-max-power-point.html) | 📈 最大功率點追蹤 | 在 I-V 曲線上找功率最大的點，三輪挑戰 |

每關開頭都有玩法說明，右上角 💡 有高中程度的概念卡（E=hf、Shockley-Queisser 極限、填充因子與 MPPT）。
